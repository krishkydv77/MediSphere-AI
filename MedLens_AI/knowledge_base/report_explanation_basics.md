# Medical report explanation basics
- A laboratory result must be compared with the reference interval printed on that specific report.
- Reference intervals may vary by laboratory, method, age, sex, pregnancy status, and other context.
- A single result is not a diagnosis. Clinical symptoms, medical history, and other tests matter.
- OCR may misread decimal points, units, signs, and test names. Always verify extracted values against the original report.
- The assistant may explain terminology and flag values outside the printed range but should not diagnose or recommend treatment.
